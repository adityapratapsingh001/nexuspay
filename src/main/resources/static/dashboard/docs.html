API Documentation

Integrate NexusPay into your application with our robust REST API.

Authentication

All API requests must include your X-API-KEY and X-API-SECRET in the headers. You can find these in your dashboard settings.

curl -X POST https://api.nexuspay.com/v1/orders \
  -H "X-API-KEY: your_api_key" \
  -H "X-API-SECRET: your_api_secret" \
  -H "Content-Type: application/json"

Create Payment Link

POST/api/gateway/create-order

Request Body

amountDecimal, Required
descriptionString, Optional
returnUrlURL, Optional

Response

{ "success": true, "url": "https://nexuspay.com/pay?q=...", "orderId": "ord_123456" }

Check Order Status

GET/api/gateway/order-status/{orderId}

Parameters

orderIdPath, Required

Sample Response

{ "orderId": "ord_123456", "status": "PAID", "amount": 500.00, "paidAt": "2026-04-26T02:40:00" }

Webhooks
